## 🔍 结果解读

### 示例输出解释

运行 `quick_start.py` 后的输出：

```
最终种群密度 (Final populations):
  N_S = 99.69    ← S-specialist 存活且达到接近携带容量
  N_M = 0.00     ← M-specialist 灭绝（被竞争排除）
  N_G = 5.04     ← Generalist 以低密度共存
```

**这意味着什么？**

1. **S-specialist (底物专家)** 占主导地位
   - 能够独立生长（基础生长率 = 1）
   - 达到接近携带容量（K_S = 100）

2. **M-specialist (代谢物专家)** 无法生存
   - 是强制性互养生物（基础生长率 = -1）
   - 在当前参数下无法从S获得足够的交叉喂养

3. **Generalist (通才)** 以低密度共存
   - 保持小种群（~5%）
   - 表明存在生态位，但竞争力不如S

---

### 平衡点类型

脚本会找到多个平衡点：

#### 平衡点 1: 灭绝
```
种群: N_S=0.00, N_M=0.00, N_G=0.00
类型: Extinction
稳定性: 不稳定 (Unstable)
```
**解释**: 所有物种都灭绝的状态。不稳定意味着任何小扰动都会导致系统离开这个状态。

#### 平衡点 2: S单独生存
```
种群: N_S=100.00, N_M=0.00, N_G=0.00
类型: S-specialist dominance
稳定性: 不稳定 (Unstable)
```
**解释**: 只有S-specialist存活。不稳定说明G可以入侵。

#### 平衡点 3: S-G共存（稳定）
```
种群: N_S=99.75, N_M=0.00, N_G=4.99
类型: S-G coexistence
稳定性: 稳定 (Stable) ✓
```
**解释**: S和G共存的稳定状态。这是系统会收敛到的长期状态。

### ω值的影响

从测试不同ω值的结果看：

| ω值 | 含义 | 最终种群 | 生态解释 |
|-----|------|---------|---------|
| 0.2 | 偏向代谢物路径 | N_S=100, N_M=0, N_G=0 | G类似M，被排除 |
| 0.5 | 平衡使用两条路径 | N_S=100, N_M=0, N_G=5 | S-G共存 |
| 0.8 | 偏向底物路径 | N_S=88, N_M=0, N_G=46 | G更强，种群更大 |

**关键发现**: ω越大（更依赖底物路径），Generalist的竞争力越强！

## ⚙️ 修改参数

### 方法一：直接在脚本中修改

编辑 `quick_start.py`:

```python
# 找到这一行（第36行左右）
model = ThreeSpeciesModel()

# 改成自定义参数
custom_params = {
    'r_S': 1.2,      # 增加S的生长率
    'r_M': 0.8,
    'r_G': 0.9,
    'K_S': 150.0,    # 增加S的携带容量
    'K_M': 100.0,
    'K_G': 100.0,
    'sigma_SM': 0.8,  # 增强合作（S从M获益）
    'sigma_MS': 0.9,  # 增强合作（M从S获益）
    'omega': 0.6,     # 调整路径权重
    # ... 其他参数
}

model = ThreeSpeciesModel(custom_params)
```

### 方法二：用Python交互式修改

```python
from three_species_model import ThreeSpeciesModel
import numpy as np

# 创建模型
model = ThreeSpeciesModel()

# 修改单个参数
model.params['omega'] = 0.7
model.params['sigma_MS'] = 0.9  # 增强M从S的受益

# 运行模拟
N0 = np.array([50, 50, 50])
sol = model.simulate(N0, (0, 100))

print(f"最终: N_S={sol['N_S'][-1]:.1f}, N_M={sol['N_M'][-1]:.1f}, N_G={sol['N_G'][-1]:.1f}")
```

### 关键参数说明

#### 生长率 (r_i)
- `r_S`, `r_M`, `r_G`: 控制物种生长速度
- 典型范围: 0.5 - 2.0
- **建议**: r_S > r_G > r_M（专家 > 通才 > 互养生物）

#### 合作系数 (σ_ij)
- `sigma_SM`: S从M获益的强度
- `sigma_MS`: M从S获益的强度（关键！）
- 典型范围: 0.2 - 0.8
- **建议**: σ_MS应该足够大（>0.5）以维持M的生存

#### 竞争系数 (α_ij)
- `alpha_SG`, `alpha_MG`: 物种间竞争强度
- 典型范围: 0.2 - 0.6
- **建议**: σ > α（合作 > 竞争）以促进共存

#### 路径权重 (ω)
- 控制Generalist的代谢策略
- 范围: 0 到 1
- **ω = 0**: 纯代谢物路径（类似M）
- **ω = 0.5**: 平衡使用两条路径
- **ω = 1**: 纯底物路径（类似S）

## 📈 理解相平面图

### 零斜线（Nullclines）

相平面图中的虚线代表 **零斜线**：

- **蓝色虚线**: dN_S/dt = 0 （S种群不变的条件）
- **红色虚线**: dN_M/dt = 0 （M种群不变的条件）

**零斜线的交点 = 平衡点**

### 向量场（Vector Field）

箭头显示种群变化的方向：

- 箭头方向：种群变化的方向
- 箭头颜色/长度：变化速度
- 轨迹沿着箭头流动

### 平衡点标记

- **绿色星星 (★)**: 稳定平衡点（吸引子）
- **红色叉号 (✗)**: 不稳定平衡点（排斥子）

## 🔧 常见问题

### Q1: 为什么M-specialist总是灭绝？

**原因**: M是强制性互养生物（基础生长率 = -1），需要满足条件：

```
σ_MS × (N_S/K_S) > 1
```

**解决方法**:
1. 增大 `sigma_MS`（例如改为0.8或0.9）
2. 降低S的自限制（增大K_S）
3. 确保初始条件中N_S足够大

示例：
```python
model.params['sigma_MS'] = 0.9  # 原来是0.6
model.params['K_S'] = 150.0     # 原来是100.0
```

### Q2: 如何实现三物种共存？

**需要同时满足**:
1. 合作强于竞争（σ > α）
2. M能生存（σ_MS足够大）
3. 适当的ω值（通常0.3-0.7）
4. 合理的初始条件

**建议参数组合**:
```python
params = {
    'sigma_SM': 0.6,
    'sigma_MS': 0.8,  # 关键：要足够大
    'sigma_SG': 0.5,
    'sigma_MG': 0.5,
    'alpha_SG': 0.3,  # 竞争要弱
    'alpha_MG': 0.3,
    'omega': 0.5,     # 中等值
}
```

### Q6: 如何批量测试参数？

import numpy as np

# 扫描omega参数
omega_values = np.linspace(0, 1, 20)

    model.params['omega'] = omega

        'omega': omega,

        'N_M_final': sol['N_M'][-1],
        'N_G_final': sol['N_G'][-1]
