# 三种群交叉喂养系统：周期轨道和极限环分析

## 问题

**这个系统会有周期轨道吗和极限环吗？如何证明？**

---

## 答案

**否。该系统在生物学相关区域（正八分空间）内不存在周期轨道或极限环。**

---

## 严格数学证明

### 方法：Dulac准则（Dulac's Criterion）

**系统方程：**
```
ds/dt = r_S · s · (1 + σ_SM·m + a·g - s)
dm/dt = r_M · m · (-1 + σ_MS·s + b·g - m)
dg/dt = r_G · g · (d + c·s + e·m - g)
```

**证明步骤：**

1. **选择Dulac函数**
   选择：$B(s,m,g) = \frac{1}{s \cdot m \cdot g}$

2. **计算散度（divergence）**
   设向量场为 $\mathbf{F} = (F_1, F_2, F_3)$，其中：
   - $F_1 = r_S s(1 + \sigma_{SM} m + a g - s)$
   - $F_2 = r_M m(-1 + \sigma_{MS} s + b g - m)$
   - $F_3 = r_G g(d + c s + e m - g)$

   计算 $\nabla \cdot (B\mathbf{F})$：

   ```
   ∂(BF₁)/∂s = ∂/∂s[r_S(1 + σ_SM·m + a·g - s)/(m·g)] = -r_S/(m·g)

   ∂(BF₂)/∂m = ∂/∂m[r_M(-1 + σ_MS·s + b·g - m)/(s·g)] = -r_M/(s·g)

   ∂(BF₃)/∂g = ∂/∂g[r_G(d + c·s + e·m - g)/(s·m)] = -r_G/(s·m)
   ```

3. **求和**
   ```
   div(B·F) = -r_S/(m·g) - r_M/(s·g) - r_G/(s·m)
            = -(r_S·s + r_M·m + r_G·g)/(s·m·g)
   ```

4. **判断符号**
   在正八分空间 $\mathbb{R}^3_+$ 内，$s, m, g > 0$ 且 $r_S, r_M, r_G > 0$，因此：

   $$\boxed{\nabla \cdot (B\mathbf{F}) < 0 \quad \text{处处成立}}$$

5. **应用Dulac定理**
   由于散度在整个感兴趣区域内**恒为负**，根据Dulac定理：

   $$\boxed{\text{不存在周期轨道}}$$

## 为什么没有周期轨道？

### 数学原因

该系统的关键特征是**自限制项**（carrying capacity terms）：

```
ds/dt 中的 -s²
dm/dt 中的 -m²
dg/dt 中的 -g²
```

这些二次项导致：
1. Jacobian矩阵对角线有负项
2. 散度 div(B·F) 恒为负
3. 系统是**全局耗散的**（globally dissipative）

对比**Lotka-Volterra捕食-被捕食系统**：
- 没有自限制项
- div(F) = 0（保守系统）
- 存在中性稳定的闭轨（neutral cycles）

### 生物学意义

交叉喂养系统的结构特征决定了其稳定性：

1. **义务性互惠**（M物种 basal growth rate < 0）
   - 创造强依赖关系
   - 防止无限制增长

2. **代谢位置分割**（ω参数调控）
   - 种群占据不同生态位
   - 避免直接竞争导致的振荡

3. **承载力限制**（$(1-s)$, $(-m)$, $(-g)$ 项）
   - 密度依赖性自限制
   - 耗散能量，使系统收敛

## 生物学含义

### 1. **群落稳定性**
交叉喂养微生物群落天然趋向稳态，不会出现永久性的"繁荣-萧条"循环。

### 2. **可预测性**
实验扰动后，系统单调松弛回平衡态，便于预测和控制。

### 3. **群落组装机制**
组成转变通过**分岔**（bifurcations）发生，而非振荡：
- 在 $\omega_{crit1}$：跨临界分岔（G入侵）
- 在 $\omega_{crit2}$：跨临界分岔（M被取代）

这是**平衡态跳跃**，不是周期吸引子。

### 4. **抗扰性**
系统抵抗周期性扰动；短暂波动会衰减而非共振成持续循环。

### 5. **工程应用**
合成生物学设计稳定的共栖系统时，可依赖此收敛性：
- 不需要担心不稳定振荡
- 平衡点可预测且可达
- 参数调控导致确定性状态转换

## 技术细节：Dulac准则

**定理陈述：**

设 $\dot{\mathbf{x}} = \mathbf{F}(\mathbf{x})$ 是区域 $D \subset \mathbb{R}^n$ 上的 $C^1$ 向量场。如果存在 $C^1$ 函数 $B: D \to \mathbb{R}$ 使得散度
$$\nabla \cdot (B\mathbf{F})$$
在 $D$ 中有**恒定符号**（总是正或总是负）且不恒为零，则系统在 $D$ 内没有周期轨道。

**我们的应用：**
- $D = \mathbb{R}^3_+ =$ {$(s,m,g) : s>0, m>0, g>0$}（单连通区域）
- $B(s,m,g) = 1/(smg)$（在 $D$ 上是 $C^1$）
- $\nabla \cdot (B\mathbf{F}) = -(r_S s + r_M m + r_G g)/(smg) < 0$ 处处成立

**所有条件满足 ⟹ 无周期轨道 ✓**
