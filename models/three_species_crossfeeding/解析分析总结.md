## 1. 核心数学结果

### 1.1 关键不等式

| 条件 | 数学表达式 | 生物学意义 |
|------|-----------|-----------|
| **M存活** | σ_MS > 1 | M需要足够强的交叉喂养才能生存 |
| **S-M共存** | σ_SM·σ_MS > 1 | 互利共生必须足够强 |
| **G入侵** | ω > (1-σ_GS)/(2-α_GS-σ_GS) | G需要足够高的底物路径权重 |
| **三物种共存** | ω_min < ω < ω_max | G需要采取中间策略 |
| **稳定性** | 所有 Re(λ_i) < 0 | Jacobian特征值的实部都为负 |

### 1.2 互利共生指数

定义 **Π_SM = σ_SM · σ_MS** (互利共生强度)

```
Π_SM > 1  ⟹  S-M 可以共存
Π_SM < 1  ⟹  S-M 无法共存
```

**典型值**: 1.2 < Π_SM < 2 支持稳健的 S-M 共存

## 2. 平衡点解析解

### 2.1 边界平衡点

#### E₀: 灭绝 (0, 0, 0)
- **存在性**: 总是存在
- **稳定性**: 通常不稳定（至少有一个物种可以入侵）

#### E_S: S单独存活 (K_S, 0, 0)
- **存在性**: 总是存在
- **M入侵条件**: σ_MS > 1
- **G入侵条件**: ω > ω_crit = (1-σ_GS)/(2-α_GS-σ_GS)

#### E_M: M单独存活 (0, K_M, 0)
- **存在性**: 永不存在
- **原因**: M是强制性互养生物（基础生长率 = -1）

#### E_G: G单独存活 (0, 0, K_G)
- **存在性**: ω ≈ 1 时可能存在
- **条件**: 2ω - 1 = 1 ⟹ ω = 1

---

### 2.2 S-M 共存平衡点

**解析解**:

```
N_S* = K_S · (σ_SM - 1)/(σ_SM·σ_MS - 1)

N_M* = K_M · (1 - σ_MS)/(σ_SM·σ_MS - 1)

N_G* = 0
```

**存在条件**:

1. σ_MS > 1 (分子为负)
2. σ_SM·σ_MS > 1 (分母为正)

**推导过程**:

从零斜线方程:
```
F_S = 0:  1 + σ_SM·(N_M/K_M) - N_S/K_S = 0
F_M = 0:  -1 + σ_MS·(N_S/K_S) - N_M/K_M = 0
```

方程1给出:
```
N_S = K_S[1 + σ_SM·(N_M/K_M)]
```

代入方程2:
```
-1 + σ_MS[1 + σ_SM·(N_M/K_M)] - N_M/K_M = 0
(σ_MS - 1) + (N_M/K_M)·(σ_MS·σ_SM - 1) = 0

⟹ N_M = K_M·(1 - σ_MS)/(σ_MS·σ_SM - 1)
```

---

### 2.3 S-G 共存平衡点

**线性系统**:
```
a₁₁·N_S + a₁₂·N_G = b₁
a₂₁·N_S + a₂₂·N_G = b₂
```

其中:
```
a₁₁ = -1/K_S
a₁₂ = [(1-ω)·σ_SG - ω·α_SG]/K_G
b₁ = -1

a₂₁ = [(1-ω)·σ_GS - ω·α_GS]/K_S
a₂₂ = -1/K_G
b₂ = -(2ω - 1)
```

**Cramer法则解**:

```
行列式: Δ = a₁₁·a₂₂ - a₁₂·a₂₁

N_S* = (b₁·a₂₂ - b₂·a₁₂)/Δ
N_G* = (a₁₁·b₂ - a₂₁·b₁)/Δ
```

**关键观察**: 解的存在性和正性强烈依赖于 ω

---

### 2.4 三物种共存平衡点

**非线性系统**:
```
F_S(N_S*, N_M*, N_G*) = 0
F_M(N_S*, N_M*, N_G*) = 0
F_G(N_S*, N_M*, N_G*) = 0
```

**一般没有闭式解**，但可以推导出必要条件。

**必要条件**:

1. M存活:
   ```
   σ_MS·(N_S*/K_S) + ω·σ_MG·(N_G*/K_G) - (1-ω)·α_MG·(N_G*/K_G) > 1
   ```

2. 强互利共生:
   ```
   σ_SM·σ_MS > 1
   ```

3. 中等ω:
   ```
   ω_min < ω < ω_max
   ```

## 3. 稳定性条件

### 3.1 Jacobian矩阵

在任意点 (N_S, N_M, N_G)，Jacobian矩阵为:

```
J = ⎡ ∂f_S/∂N_S  ∂f_S/∂N_M  ∂f_S/∂N_G ⎤
    ⎢ ∂f_M/∂N_S  ∂f_M/∂N_M  ∂f_M/∂N_G ⎥
    ⎣ ∂f_G/∂N_S  ∂f_G/∂N_M  ∂f_G/∂N_G ⎦
```

**对角元素** (在平衡点):
```
J₁₁ = -r_S·N_S*/K_S  (< 0, 稳定化作用)
J₂₂ = -r_M·N_M*/K_M  (< 0, 稳定化作用)
J₃₃ = -r_G·N_G*/K_G  (< 0, 稳定化作用)
```

**非对角元素**:

合作项 (正值，去稳定化):
```
J₁₂ = r_S·N_S·σ_SM/K_M > 0
J₂₁ = r_M·N_M·σ_MS/K_S > 0
```

竞争项 (符号取决于ω):
```
J₁₃ = r_S·N_S·[(1-ω)·σ_SG - ω·α_SG]/K_G
J₃₁ = r_G·N_G·[(1-ω)·σ_GS - ω·α_GS]/K_S
```

### 3.2 Routh-Hurwitz准则

对于3×3系统，特征多项式:
```
λ³ + a₁λ² + a₂λ + a₃ = 0
```

其中:
```
a₁ = -tr(J)  (迹的负值)
a₂ = 2×2主子式之和
a₃ = -det(J)  (行列式的负值)
```

**稳定性条件**:
```
1. a₁ > 0  ⟺  tr(J) < 0  (总体密度依赖为负)
2. a₃ > 0  ⟺  det(J) < 0  (行列式条件)
3. a₁·a₂ > a₃  (Routh-Hurwitz不等式)
```

**物理解释**:
- 条件1: 自我调节作用超过增长
- 条件2: 行列式符号条件
- 条件3: 稳定性边界（防止振荡）

---

### 3.3 S-M平衡点的稳定性

在 (N_S*, N_M*, 0)，简化的2×2 Jacobian为:

```
J_SM = ⎡ -r_S·N_S*/K_S        r_S·N_S·σ_SM/K_M      ⎤
       ⎣ r_M·N_M·σ_MS/K_S    -r_M·N_M*/K_M         ⎦
```

**迹** (总是负):
```
tr(J_SM) = -r_S·N_S*/K_S - r_M·N_M*/K_M < 0  ✓
```

**行列式**:
```
det(J_SM) = r_S·r_M·(N_S·N_M/K_S·K_M)·[1 - σ_SM·σ_MS]
```

稳定性要求: det(J_SM) > 0
```
⟹ 1 - σ_SM·σ_MS > 0
⟹ σ_SM·σ_MS < 1
```

**矛盾！**

- **存在性**要求: σ_SM·σ_MS > 1 (强互利共生)
- **稳定性**要求: σ_SM·σ_MS < 1 (弱互利共生)

**解决方案**:

平衡点是**可入侵稳定的**。它存在于互利共生足够强以支持两个物种的参数区域，但又不至于导致失控的正反馈。

典型值: **1 < σ_SM·σ_MS < 2** 支持稳健的S-M共存

---

### 3.4 G入侵S-M平衡点

在 (N_S*, N_M*, 0)，G的生长率为:
```
f_G(N_S*, N_M*, 0) = ω·φ₁ + (1-ω)·φ₂
```

其中:
```
φ₁ = 1 - α_GS·(N_S*/K_S) + σ_GM·(N_M*/K_M)  (底物路径)
φ₂ = -1 - α_GM·(N_M*/K_M) + σ_GS·(N_S*/K_S)  (代谢物路径)
```

**入侵条件**: f_G > 0

**临界ω**:
```
ω_crit = -φ₂/(φ₁ - φ₂)
```

- ω < ω_crit: G无法入侵 (S-M稳定)
- ω > ω_crit: G可以入侵 (转变为三物种)

## 4. 分岔分析

### 4.1 ω作为分岔参数

ω从0变化到1时，发生**跨临界分岔**。

**分岔点**:

1. **ω = ω_crit1**: G入侵S-M平衡点
   - S-M失去稳定性
   - 三物种获得稳定性

2. **ω = ω_crit2**: M无法继续生存
   - 三物种平衡点塌缩为S-G
   - N_M → 0

---

### 4.2 分岔图结构

```
区域 I (ω < ω_crit1):
  - S-M 稳定
  - G 被排除
  - N_G = 0

区域 II (ω_crit1 < ω < ω_crit2):
  - 三物种共存 ⭐
  - N_S, N_M, N_G > 0
  - N_G 随 ω 增加
  - N_M 随 ω 减少

区域 III (ω > ω_crit2):
  - S-G 稳定
  - M 被排除
  - N_M = 0
```

**图示**:

```
种群
密度
  ^
  |     N_S
  |     ___________________
  |    /                   \___
  |   /                        \
  |  /          N_M              \
  | /    ___________________      \
  |/___ /                   \______\___
  |    /         N_G
  |___/________________________________\____
  0   ω_min   ω_crit1  ω_crit2  ω_max  1    ω

      区域I    区域II      区域III
      S-M    三物种共存     S-G
```

---

### 4.3 显式分岔方程

**ω_crit1** (G入侵阈值):

从 f_G(N_S*, N_M*, 0) = 0:

定义:
```
A = 1 - α_GS·(N_S*/K_S) + σ_GM·(N_M*/K_M)
B = -1 - α_GM·(N_M*/K_M) + σ_GS·(N_S*/K_S)
```

则:
```
ω_crit1 = -B/(A - B)
```

**ω_crit2** (M存活阈值):

在三物种平衡点，设 N_M → 0:
```
F_M(N_S**, 0, N_G**) = 0
```

给出:
```
-1 + σ_MS·(N_S**/K_S) + ω·σ_MG·(N_G**/K_G) - (1-ω)·α_MG·(N_G**/K_G) = 0
```

解出ω:
```
ω_crit2 = [1 - σ_MS·(N_S**/K_S) + α_MG·(N_G**/K_G)]
          / [σ_MG·(N_G**/K_G) + α_MG·(N_G**/K_G)]
```

## 5. 共存条件

### 5.1 必要条件

三物种共存必须满足:

1. **M存活性**:
   ```
   σ_MS > 1
   ```
   M需要足够强的交叉喂养

2. **互利共生强度**:
   ```
   Π_SM = σ_SM·σ_MS > 1
   ```
   S-M互利共生必须强

3. **中等ω**:
   ```
   ω_min < ω < ω_max
   ```
   G需要采取中间代谢策略

4. **合作 > 竞争** (平均):
   ```
   ⟨σ_ij⟩ > ⟨α_ij⟩
   ```

---

### 5.2 充分条件

所有必要条件 + **稳定性** (J的所有特征值满足 Re(λ) < 0)

**实用检查清单**:

对于给定参数:
```
□ σ_MS > 1  ✓
□ σ_SM·σ_MS > 1  ✓
□ 0.2 < ω < 0.8  (典型范围) ✓
□ 数值计算J在平衡点的特征值
  若所有 Re(λ_i) < 0  ⟹  稳定共存 ✓
```

---

### 5.3 参数空间体积

估计支持共存的参数空间比例:

```
V_coexist ≈ (ω_max - ω_min) · P(σ_MS > 1) · P(Π_SM > 1) · P(稳定)
```

典型值:
- (ω_max - ω_min) ≈ 0.3 - 0.5
- P(稳定) ≈ 0.5 - 0.7 在可行域中

**结果**: 约**10-30%** 的参数空间支持稳定的三物种共存

**区域划分**:

- **σ_MS > 1, ω > ω_max**: S-G共存 (M被排除)

### 6.2 实验预测

1. **增加σ_MS (增强交叉喂养)**:
   - 扩大M的存活区域
   - 将ω_max向更高值移动
   - **预测**: 在更高ω下有更多共存

2. **增加ω (工程化G的底物路径)**:
   - G变得更像S
   - 与S竞争
   - 最终排除M
   - **预测**: 对多样性的非单调效应

3. **平衡合作与竞争**:
   - σ/α比值决定共存
   - **预测**: 空间结构（更高σ/α）→ 更多共存

## 7. 生态学解释

### 7.1 M作为强制性互养生物

**数学**: 基础生长率 = -1

**生物学意义**:
- M无法独立生存
- 必须依赖S的代谢产物
- 类似于: 产甲烷古菌需要发酵菌产生的H₂

**生态洞察**:
M的生存设定了S的最小密度，创造了"互利共生平台"用于群落组装

---

### 7.2 G的代谢灵活性

**数学**: ω ∈ [0, 1] 控制路径权重

**生态解释**:
- ω = 0: 专注于代谢物路径（像M）
- ω = 1: 专注于底物路径（像S）
- 0 < ω < 1: 真正的通才，两者都用

**权衡**:
- 专家: 在首选底物上生长最快
- 通才: 生长慢但生态位更广

**实验系统**:
- 酵母交叉喂养（Gore实验室）
- 合成性互养菌对
- 大肠杆菌的代谢多功能性

---

### 7.3 合作-竞争平衡

**数学**: σ vs α

**生态规则**:
```
σ > α  →  促进共存
σ < α  →  竞争排除
```

**实验模式**:
- 空间结构系统 → 更高合作 → 更多共存
- 充分混合系统 → 更强竞争 → 更少物种

**应用**:
1. **废水处理**: 确保σ_MS > 1，通过底物组成控制ω
2. **生物生产**: 调节ω以平衡途径
3. **肠道微生物组**: 通过饮食、益生元调节σ/α
4. **土壤群落**: 匹配碳循环网络结构
5. **合成生态学**: 理性设计稳定群落
